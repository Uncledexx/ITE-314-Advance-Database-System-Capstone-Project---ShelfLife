PROJECT TITLE:

SHELFLIFE: A WEB-BASED PERSONAL PANTRY AND
EXPIRATION DATE TRACKER


============================================================
                    1. PROJECT OVERVIEW
============================================================

ShelfLife is a web-based pantry management system designed
to help users organize and monitor food items stored at home.

The system allows users to record pantry items, manage
quantities, monitor expiration dates, and identify food that
is expiring soon or has already expired.

Users can also mark food items as consumed. Consumed items
can be recorded in a history section so that users can keep
track of previously used food.

The system will use Node.js and Express.js for the backend
and MySQL as the relational database.


============================================================
                    2. PROJECT GOAL
============================================================

The main goal of ShelfLife is to provide a simple and
organized way for users to manage their pantry inventory
while helping them monitor expiration dates and reduce
unnecessary food waste.

============================================================
                    9. EXPIRATION TRACKING
============================================================

PURPOSE:

Automatically determine the status of pantry items based on
their expiration date.

STATUS TYPES:

AVAILABLE
- More than 7 days before expiration

EXPIRING SOON
- 1 to 7 days before expiration

EXPIRED
- Expiration date has already passed

CONSUMED
- User has already eaten or used the item


EXAMPLE:

Milk
Expiration: September 30

Current Date: September 27

Status:
EXPIRING SOON


IMPORTANT:

The user does not need to manually enter the expiration
status. The system calculates the status based on the
expiration date.

============================================================

Allows users to update the pantry when they have eaten or
used a food item.

EXAMPLE:

Milk

NEW QUANTITY:
1


The system should allow the user to either:

A. Reduce the quantity

OR

B. Mark the entire item as consumed


RECOMMENDED:

If quantity becomes 0:

Milk
Quantity: 0
Status: Consumed


The item is removed from the active pantry list and stored
in the Consumption History.

============================================================
                    26. PROJECT SCOPE
============================================================

ShelfLife will focus on personal pantry management.

The project will NOT include:

- Online grocery shopping
- Online payments
- Barcode scanning
- AI food recognition
- Delivery services
- Advanced nutritional tracking
- Automatic grocery ordering


The purpose of limiting these features is to keep the project
manageable for a mini-capstone while still demonstrating
database management and Node.js development.

                    28. PROJECT OBJECTIVE

ShelfLife aims to provide users with a simple web-based
system for managing pantry inventory, monitoring expiration
dates, updating food quantities, and recording consumed items.

The project also demonstrates the practical application of

development, and server-side programming using Node.js.
